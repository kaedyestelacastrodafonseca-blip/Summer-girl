# Summer-girl
🌴 Summer Girl

🩷 Sobre o projeto

A Summer Girl é uma loja virtual de roupas femininas com inspiração no verão e na moda praia. O projeto foi desenvolvido como trabalho acadêmico utilizando HTML, CSS e JavaScript.
